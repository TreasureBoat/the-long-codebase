Two developers, one twenty-year-old codebase, and an AI.

Most writing about AI and software is about code that does not exist yet. This is about the
other kind — long-lived production systems with real customers, where a mistake means a
Sunday spent restoring a database rather than a failed build.

We modernize systems like that for other people. This is where we write up the work,
including the parts that went wrong — and there are always parts that went wrong.
[What we take on]({{ '/work/' | relative_url }}).
